# 작업 방식 정리

## 공통

- **GUI**: 시작 / 중지 버튼으로 워커 실행·종료. ESC 키로도 중지.
- **니모닉 시도 횟수**: `data/mnemonic_attempt_count.txt`에 저장·표시.
- **모드 선택**: 상단 콤보박스에서 **SafePal** / **Trust Wallet** / **Tron Network** 중 선택 후 시작.

---

## 1. SafePal 모드

| 항목 | 내용 |
|------|------|
| **캡처** | Edge 창 (또는 포커스 창) |
| **템플릿** | `data/pic/kr/` |
| **흐름** | First Set(메뉴→추가→지갑가져오기→니모닉→next) → Second Set(슬롯 1~12에 니모닉 입력) → success 이미지 감지 → 발견 시 confirm→x 클릭, **12회 성공 시** 지갑 삭제 프로세스(mainpage_menu→delete→delete2→delete3→비밀번호→delete4) 후 처음부터 재시작 |
| **니모닉** | `data/wordlist.txt`에서 랜덤 12단어 (이미지 입력용, BIP39 체크섬 무관) |
| **비밀번호** | GUI 비밀번호 칸 → 삭제 시 사용 |

---

## 2. Trust Wallet 모드

| 항목 | 내용 |
|------|------|
| **캡처** | Chrome 창 |
| **템플릿** | `data/pic/trustwallet/` |
| **흐름** | First Set(first→second→third 대기→third→fourth→fifth→니모닉 Ctrl+V) → error.png 있으면 fail, 없으면 일정 시간 후 successbutton 클릭 → success 감지 시 successbutton→success→Ctrl+W. **실패 시** 저장된 fifth 좌표로 재클릭 후 Ctrl+A·새 니모닉. **성공 13회** 또는 second 후 limit 감지 시 manage→(manage2,3,4)×13→manage5 후 **second부터** 재시작. **password 이미지** 감지 시 비밀번호 플로우(password→비번 입력→password2→selection1~4) 후 first부터 복귀. |
| **니모닉** | `data/wordlist.txt`에서 랜덤 12단어 (Chrome에 입력) |
| **비밀번호** | GUI 비밀번호 칸 → 지갑 삭제/비밀번호 플로우 시 사용 |

## 3. Tron Network 모드

| 항목 | 내용 |
|------|------|
| **캡처** | 없음 (브라우저/이미지 사용 안 함) |
| **흐름** | ① BIP39 유효 니모닉 12단어 생성(NBitcoin) → ② BIP44 경로 `m/44'/195'/0'/0/0`로 Tron 개인키·주소 파생 → ③ TronGrid API로 해당 주소 **TRX** 잔고 + **USDT(TRC20)** 잔고 조회 → ④ 로그에 주소·TRX·USDT 출력. 잔고 있으면 HIT(빨간색) + `data/tron_hit_phrases.txt`에 기록. ①~④ 반복. |
| **API** | `https://api.trongrid.io` (getaccount, triggerconstantcontract). API 키: `data/tron_api_key.txt` 또는 exe 폴더 `tron_api_key.txt` (없으면 요청 제한될 수 있음) |
| **로그** | " 니모닉 문구 탐색중 [N] 시도중" 한 줄은 갱신만 하고, 조회 결과(주소·TRX·USDT)는 새 줄로 출력. |

**참고**: 랜덤 니모닉으로 잔고 있는 주소를 찾을 확률은 극히 낮음. 200회 정도로 HIT가 안 나오는 것은 정상.

## 빌드별 결과

| 빌드 | 결과 폴더 | 비고 |
|------|-----------|------|
| `dotnet publish -c Release /p:PublishProfile=SingleFileProfile` | `publish/` | **통합 GUI** (세 모드 선택 가능) |
| `dotnet publish /p:PublishProfile=TrustWalletProfile /p:Configuration=ReleaseTrustWallet` | `publish-trustwallet/` | Trust Wallet 전용 |
| `dotnet publish /p:PublishProfile=TronCliProfile /p:Configuration=ReleaseTronCli` | `publish-troncli/` | **콘솔 전용** (GUI 없음, `--count N` 등) |
