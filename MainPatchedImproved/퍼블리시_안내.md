# 실전 테스트용 퍼블리시

- **Visual Studio**: 프로젝트 우클릭 → **게시** → 기존 프로필 선택 또는 **FolderProfile** 선택 후 게시.
- **터미널**: .NET SDK 설치 후 아래 명령 사용.

## 1. 폴더 배포 (권장)

- **방법 1**: `publish.bat` 더블클릭  
- **방법 2**: 터미널에서  
  ```bash
  dotnet publish -p:PublishProfile=FolderProfile
  ```
- **결과**: `bin\Publish\` 폴더
  - `MainPatchedImproved.exe` 실행
  - `pic\kr\` 이미지 템플릿, `wordlist.txt` 포함됨 (프로젝트에서 복사)
  - 이 폴더 통째로 복사해서 다른 PC에서 실행 가능 ( .NET 설치 불필요 )

## 2. 단일 exe 배포

- 터미널에서  
  ```bash
  dotnet publish -p:PublishProfile=SingleFileProfile
  ```
- **결과**: `bin\Publish-SingleFile\MainPatchedImproved.exe`  
- **주의**: `pic\kr\`, `wordlist.txt`는 exe와 **같은 폴더**에 두어야 함 (실행 파일 옆에 복사 필요).

## 3. 배포 전 확인

- [ ] `pic\kr\` 안에 필요한 png 템플릿 모두 있음
- [ ] `wordlist.txt`가 exe와 같은 폴더(또는 Publish 폴더)에 있음
- [ ] 실전 PC에서 한 번 실행해 보고, **단계별 테스트**로 이미지/동작 확인

## 4. 문제 시

- **한글 깨짐**: `publish.bat`은 UTF-8로 실행됨.
- **exe만 배포**: 폴더 배포 시 `bin\Publish` 전체를 zip으로 압축해 배포하면 됨.
